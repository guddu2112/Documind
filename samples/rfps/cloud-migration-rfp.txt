1. INTRODUCTION

Northwind Traders, Inc. ("Northwind") is seeking proposals from qualified
vendors to modernize its on-premises IT infrastructure by migrating
workloads to a public cloud platform. This RFP outlines the scope of work,
evaluation criteria, and submission requirements.

4. SCOPE OF WORK

The selected vendor shall provide the following services:

4.1 Assessment & Planning
  - Conduct a comprehensive inventory of existing on-premises workloads
    (approximately 120 virtual machines, 15 databases, 8 web applications).
  - Develop a migration roadmap with phased approach over 12 months.
  - Identify dependencies and risk mitigation strategies.

4.2 Migration Execution
  - Migrate all identified workloads to the target cloud platform.
  - Implement infrastructure-as-code (IaC) for all provisioned resources.
  - Configure networking, security groups, and identity management.
  - Establish CI/CD pipelines for application deployments.

4.3 Optimization & Handover
  - Right-size cloud resources based on actual utilization metrics.
  - Implement cost monitoring and alerting dashboards.
  - Conduct knowledge transfer sessions (minimum 40 hours).
  - Provide 90-day post-migration hypercare support.

5. REQUIREMENTS

Mandatory Requirements:
  R1. Vendor must have at least 5 completed cloud migration projects of
      similar scale (100+ VMs) within the last 3 years.
  R2. Proposed team must include at least 2 certified cloud architects.
  R3. Vendor must demonstrate experience with healthcare data compliance
      (HIPAA).
  R4. Migration must achieve zero unplanned downtime for Tier-1 applications.
  R5. All infrastructure must be defined as code (Terraform, Bicep, or
      equivalent).

Optional Requirements:
  R6. Experience with Kubernetes orchestration for containerized workloads.
  R7. Ability to implement FinOps practices and cost governance frameworks.
  R8. Multi-cloud strategy consulting capabilities.
